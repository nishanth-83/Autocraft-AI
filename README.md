# AUTOCRAFT AI

### AI-Powered Desktop Automation Agent

AUTOCRAFT AI is an intelligent desktop automation system designed to execute user tasks through AI-powered planning, browser automation, and desktop control.

## Features
- AI-powered task planning
- Browser automation using Playwright
- Desktop automation
- File management
- Task validation
- Error recovery
- Execution monitoring

## Technologies Used
- Python
- React
- TypeScript
- FastAPI
- Playwright
- Vite

## Project Structure
- backend/
- frontend/
- tests/
- docs/
